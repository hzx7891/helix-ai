本地优先

常见问题

你可能想知道

需要什么运行环境？
只需要 Node.js 20 或更高版本。不需要 Docker，不需要编译工具链， 也没有构建步骤——npx helix-ai-cn 拉下来就能直接跑。
数据会被上传吗？
界面、工具调用和会话记录全部在本地运行，API Key 与聊天记录保存在 ~/.helix/ 目录下。只有在你主动发起模型请求时，对话内容才会 发送给你自己配置的模型服务商。
支持哪些模型？
任何兼容 OpenAI 接口规范的服务都可以接入。你只需要在设置里填入 Base URL 和 API Key，无需经过任何中转层。
工具调用会不会失控？
内置了操作审批、调用限流和审计日志三层机制。涉及写文件、执行命令这类 有副作用的操作时，会先弹出确认，由你决定是否放行。
为什么体积这么小？
整个项目只依赖 express 和 ws，没有前端框架、 没有打包器、没有 CDN 资源。发布包 87 KB，解压后 312 KB。
